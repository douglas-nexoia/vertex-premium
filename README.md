# VERTEX — Referência Técnica em Equipamentos Premium Importados

Website institucional de alto padrão da **VERTEX**, especializada em diagnóstico, instalação, manutenção preventiva e consultoria técnica para marcas de eletrodomésticos premium importados.

## 🚀 Marcas Atendidas

- Viking
- Sub-Zero
- Wolf
- Miele
- Bertazzoni
- Gaggenau
- Liebherr
- Tecno
- Elettromec

## 🛠️ Tecnologias Utilizadas

- HTML5 Semântico
- CSS3 (Vanilla, CSS Variables, Flexbox, CSS Grid, Responsive Design)
- JavaScript (ES6+, IntersectionObserver, Form Validation)
- Vercel Ready (Zero-config static hosting)

## 📦 Hospedagem na Vercel

Este repositório está configurado para deploy automático na Vercel.

1. Importe o repositório na Vercel (`douglas-nexoia/vertex-premium`).
2. Selecione o Framework Preset: **Other** (Static HTML).
3. Clique em **Deploy**.
